# ADR-003: 관리대장은 기존 xlsx 워크북에 행만 추가
대상: `<SAD-R003>`
상태: 채택

## 맥락
분류 결과를 남길 기록 저장소를 정한다.

The PRD (`<PRD-U003>`) and SRS revision `00.01` (`<SRS-F030>`, `<SRS-F033>`, §8.4) require results in the existing submission ledger workbook, backed up before writing, with existing rows, sheets, formulas and formats unchanged.

## 결정
사용자의 기존 xlsx 워크북을 기록 원본으로 삼고 백업 후 행 추가만 한다.

The system backs up the workbook to `project_root/backup`, locates 8 columns by header name and appends rows below the last data row. It never creates or repairs headers or sheets and keeps no separate system database.

## 고려한 대안
시스템 전용 저장소를 검토했다.

- A system-owned database or file with an export to Excel.
- Rewriting the workbook from the system's own model on every run.

## 선택 근거
사람이 이미 쓰는 업무 산출물의 구조를 지키고 실행마다 복구 가능하게 한다.

The ledger is a shared business deliverable people open and edit in Excel. Append-only writing plus a pre-run backup preserves their structure and makes every run recoverable; the alternatives would make the workbook a derived copy and risk overwriting manual edits.

## 되돌리는 비용
사용자 산출물·잠금 계약·감사 근거가 함께 바뀐다.

Reversal changes the user's deliverable, the lock handling and exit code 2 contract, and every audit or report built on the workbook rows. Cost: 높음.
