# 사람 실테스트 안내

`issue/3.done/`에는 에이전트 조치와 자동검증을 마치고 사람 확인을 기다리는 ISSUE가 있다.

1. 각 ISSUE의 재현 조건과 기대 결과를 실제 결과물에서 확인한다. 여러 이슈를 함께 확인할 때는 이 폴더에 한 장의 체크리스트를 둔다.
2. 확인 결과와 사용한 결과물·입력·날짜를 ISSUE 또는 `issue/results/`에 남긴다. 실패는 같은 ISSUE를 `2.todo`(원인 확정) 또는 `1.open`(원인 미확정)으로 돌린다.
3. 통과를 명시한 뒤 사람이 직접 `4.archive`로 옮기거나 에이전트에게 이동을 요청한다. 에이전트는 자동시험만으로 사람 확인을 대신하지 않는다.

`tests/`는 구현 자동시험이며 `vv`는 사람의 실제 사용 확인 단계다. 게이트는 `1.open`·`2.todo`·`3.done` 중 하나라도 있으면 FAIL이다.
